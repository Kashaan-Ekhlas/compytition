# Compytition: Event Hosting and Judging Platform
## Problem
**As an event organizer who organizes events, I find existing platforms**
- Too cluttered (UnStop)
- Too rigid in terms of scoring (Devfolio)

**As a student who participates in events, I face**
- Unfair results in marks when some judges are strict while others are lenient
- Difficulties finding events in cluttered platforms.
- Frustration when other people can add without permission and I'm unable to leave

**As a judge who judges in events, I face**
- Frustration while scoring as I have to check score weights constantly

## Vision and Opportunity
**We just want a simple, clutter-free, non-rigid, and fast use platform**
- Event Hosting Market estimated to reach 56.93 billion dollars of value by 2034
Source: https://www.fortunebusinessinsights.com/virtual-event-platform-market-105921
- Multiple websites have been able to capitalise on the event market (UnStop, Devfolio)

## Proposed Solution
Offer a simple, event hosting and judging platform. No ads. Hosting Fees for enterprises, none for student clubs.

*Top 3 MVP Props:*
- Minimalistic but configurable.
- Fewest taps to for judgind events and finding events to reduce cognitive load.
- Eliminate unfair scoring to reduce biases faced by users.

## Requirements
Legend: [P0] = MVP, [P1] = Important, [P2] = Nice-to-have.
1. User Accounts and Profiles

    [P0] Users can register, log in, and log out.

    [P0] Users can set a unique username and change their password.

    [P0] Users can view and edit their profile.

    [P0] Users can save common information, such as name, college, course, and year of study.

    [P0] Users can securely access only the resources they have permission to use.

    [P0] Users can sign in using Google or other supported providers.

2. Event Discovery

    [P0] Users can discover published events on a dedicated page.

    [P0] Users can search events by name and keywords.

    [P0] Users can filter events by category, participation format, and registration status.

    [P0] Users can view event details, deadlines, eligibility, and team requirements.

    [P1] Users can bookmark events for later.

3. Event Hosting

    [P0] Organizers can create, edit, publish, and manage events.

    [P0] Organizers can configure event details, registration deadlines, and team size limits.

    [P0] Organizers can customize registration forms with required and optional fields.

    [P0] Organizers can manage participants, submissions, and judges.

    [P0] Organizers can configure judging criteria and finalize results.

    [P1] Organizers can duplicate previous events and export results.

4. Team Formation

    [P0] Users can create a team and set a team name.

    [P0] Team owners can invite members and approve or reject join requests.

    [P0] Users can leave teams without requiring arbitrary approval.

    [P0] Only authorized members can modify team details and membership.

    [P0] Teams must follow the event's configured size limits.

    [P1] Users can discover teams looking for members.

5. Registration and Submissions

    [P0] Users can register for events individually or as teams, depending on event settings.

    [P0] Registration forms automatically populate information from user profiles.

    [P0] Users can review autofilled information and answer event-specific questions.

    [P0] Users can view their registered events and registration status.

    [P0] Participants can submit and update their work before the deadline, where permitted.

    [P1] Users can receive deadline reminders.

6. Pairwise Judging

    [P0] Judges can compare two submissions at a time and select the stronger submission.

    [P0] Judges can view submissions and judging criteria while comparing.

    [P0] Judgments are saved and judges can resume incomplete sessions.

    [P0] Organizers can assign multiple judges and configure judging coverage.

    [P0] CrowdBT-based aggregation combines pairwise judgments into an overall ranking.

    [P0] Organizers can review and publish finalized results.

    [P1] Organizers can inspect judging disagreements and comparison coverage.

7. Dashboard and Settings

    [P0] Users can view their events, registrations, teams, and pending invitations.

    [P0] Organizers can access the events they manage.

    [P0] Judges can access their assigned events and pending comparisons.

    [P0] Users can edit profile settings, change passwords, and log out.

    [P0] Users can report bugs and submit feedback.
